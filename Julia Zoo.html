朱利亚动物园 · Julia Zoo

曼德博集合不是一张壁纸，而是一张图鉴：复平面上每个点 c 代表一个不同的动力系统 z ↦ z² + c，点一下就能看见它对应的那只“动物”。

这个页面在玩什么

曼德博集合 M 是复平面上那些“轨道不逃向无穷”的 c 的集合。每个像素算一次：从 z = 0 出发反复做 z ← z² + c，如果几百步之后 |z| 还很小，这个 c 就属于集合 —— 右下角那张小图里那片黑色。

对每个 c，同一套迭代还定义了另一个图形：朱利亚集 J(c)，它是“所有起点里轨道不发散的那些点”。M 是参数的世界，J 是状态的世界 —— 主屏放的就是当前 c 的 J(c)。

它们之间的桥：c 在 M 里时，J(c) 是一条连通的曲线；c 不在 M 里时，J(c) 碎成无数尘埃（康托集）。所以按住图鉴慢慢移动，主屏的形状就在“一整条”和“飞散的尘埃”之间反复切换。

背后的数学

复数迭代与逃逸　z ↦ z² + c 是最简单的非线性多项式。复数乘法本身就是“旋转 + 缩放”，所以每一步都在把身体转一下、拉一下。一旦 |z| > 2 就必然发散（因为 |z²| = |z|²，增长比线性快得多）—— 2 就是逃逸半径，而跑出去的步数 n 就是“跑得多快”。

曼德博 ⊥ 朱利亚：一组对偶　曼德博固定起点 z₀ = 0、变化参数 c（参数空间）；朱利亚固定 c、变化起点 z₀（状态空间）。同一个公式，两种切法 —— 这是复动力系统里最核心的视角切换。

连通性二分定理　Douady 与 Hubbard 证明：J(c) 连通 ⟺ c ∈ M。这不是画出来的巧合，是可证明的拓扑结论（Fatou–Julia 理论）。换句话说，M 是“所有连通世界”的参数地图 —— 图上每一处黑色，都对应一整块不会碎掉的宇宙。

心形、圆盘与周期岛　M 内部由“双曲分量”填满：主心形对应吸引不动点（周期 1），边界公式是 c = e^{iθ}/2 − e^{2iθ}/4；左边那个小圆盘是周期 2 的分量 |c+1| = 1/4；再往外是周期 3、4、5…的小岛，按周期递增排列，而且图案自相似。打开“周期边界”就能看见它们。

光滑染色 = 等势线　直接按迭代次数上色会有一条条色带。用连续化的 μ = n + 1 − log₂ log|z| 就得到平滑过渡：它实际上是外部势函数 log|zₙ|/2ⁿ 的等值线。所以那片颜色的每一道弧，都是一条等势线。

边界维数 = 2，但面积 = 0　Shishikura 在 1991 年证明 M 边界的豪斯多夫维数恰好是 2：它“填满”了平面的每一个粗糙角落，可面积却是零。这就是它怎么放大都有新细节的原因 —— 不是像素不够，是结构真的无限深。

怎么玩

  • 主屏是当前 c 的朱利亚集；右下角的小图是曼德博图鉴本身，黄点就是 c 的位置。按住图鉴取样（主屏立刻变成那只动物），松开自动复位；双击图鉴把当前这只固定下来。
  • 主屏：滚轮缩放、拖动平移、双击切到曼德博全图。
  • 左栏：M / J / 自动漫游 切换；迭代上限滑块（缩得越深越要调大）；四种配色；周期边界；保存 PNG。
  • 快捷键：M / J / A 切视图，R 重置，P 换色，B 边界，+ / − 调迭代。

值得盯着看的

  • 沿着主心形边界慢慢走：经过的吸引周期依次是 1、2、3…，主屏里的朱利亚集从圆润变尖、变刺，最后碎成尘埃。
  • 海马谷：把视角推到 c ≈ (−0.745, 0.113)，缩进去能看见小号的曼德博集合复制品 —— 自相似。
  • 打开“周期边界”再缩放：主心形外面那一串圆盘，其实是周期 2、3、4 的卫星分量。
